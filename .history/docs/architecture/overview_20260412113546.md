# Architecture Overview

- Vue: 前端工作台
- FastAPI: API 接入层
- LangGraph: 工作流骨架
- LlamaIndex: 知识能力层


## 当前阶段定位与旧系统接入边界

OrionStack 当前阶段的定位，不是替代企业既有 ERP、OA、权限系统或历史工具封装层，  
而是以 **非侵入方式** 将 LLM 能力接入现有体系，在知识问答与建议层优先创造价值。

这意味着，在当前阶段：

- 旧 ERP / OA / 权限系统仍然是事实来源与最终执行系统
- 既有 Tool 封装层允许继续保留，不要求为接入 OrionStack 立即停用
- OrionStack 首期主要承担 AI 交互层、知识增强层、建议层与工作流编排层职责
- 首期默认以只读能力与建议型能力为主，不将自动执行作为主链路目标

## 当前阶段主链路

当前主链路聚焦于 **知识助手 / 文档问答 MVP**，目标是打通：

- 文档上传
- 索引构建
- 检索问答
- 引用返回
- 会话、日志与反馈基础链路

当前阶段明确不做：

- 客服 / 工单 / 运维等多场景并行扩张
- 自动审批、自动流转、自动写入旧系统
- 大而全平台后台
- 通用 Agent 平台

## 首期最重要的能力优势

当前阶段不以“覆盖场景越多越好”为目标，  
而以“少数关键能力是否做深”为目标。

首期最重要的能力优势包括：

### 1. 可追溯引用
回答不仅要能输出结论，还要能指出依据来自哪份文档、哪段内容。

### 2. 权限感知检索
系统只能基于用户有权限访问的内容进行检索与回答，权限边界不依赖模型自行判断。

### 3. 建议型流程辅助
对于 ERP / OA / 旧 Tool 相关问题，首期优先输出建议、步骤、入口与参数草稿，而不是自动执行。

### 4. 反馈闭环
记录问答结果、引用结果与用户反馈，为后续检索优化与知识清洗提供依据。

## 当前阶段一句话总结

OrionStack 当前阶段是一个面向企业旧系统环境的 **知识问答与建议型 AI 应用底座 MVP**。  
它不替代旧系统，而是在旧系统之上，以可控、可追溯、可逐步扩展的方式接入 LLM 能力。
