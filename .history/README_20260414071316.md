# OrionStack

企业 AI 应用底座仓库骨架。

## 目标

本仓库用于承载 OrionStack 首期 MVP：**企业知识助手 / 文档问答**。

核心目标：

- 支持文档上传与索引
- 支持基于文档的检索问答
- 支持引用展示
- 支持会话、日志与反馈
- 为后续客服 / 工单 / 运维场景扩展预留清晰边界

## 目录概览

```text
orionstack/
├── frontend/
├── backend/
├── docs/
└── README.md
```

## 技术分工

- `frontend/`: Vue 工作台与页面
- `backend/`: FastAPI + LangGraph + LlamaIndex 后端骨架
- `docs/`: 架构、产品与 API 文档

## 首期 MVP 范围

- 文档上传 / 文档列表
- 文档解析与索引（占位）
- 知识问答（占位）
- 引用返回结构（占位）
- 会话、日志、反馈（占位）

## 启动建议

后续可在：

- `backend/app/api/routes/` 中补路由
- `backend/app/workflows/knowledge_assistant/` 中补 LangGraph 工作流
- `backend/app/knowledge/` 中补文档接入、索引与检索实现
- `frontend/src/pages/` 中补知识助手与文档管理页面
